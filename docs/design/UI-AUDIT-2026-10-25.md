# Console UI/UX audit — 25 Oct 2026

Scope: Admin and Developer panels (`apps/console`) on branch `feat/additional-requirements`, against the owner's 13
screenshots (18:36 and 18:45) and the code. Evidence labels per CLAUDE.md rule 7. Measurements come from a headless
Chromium probe on the local stack (1440×900, seeded data plus 46 locally created requests).

## P0 — breaks reading or interaction

| # | Problem (screenshot) | Cause in code | Fix | Where |
|---|---|---|---|---|
| 1 | Rows show **above** the sticky table header on Requests while scrolling (18:36:15) | OBSERVED: the list scroller is `overflow-auto pt-3`; `th` is `sticky top-0`, and a sticky box pins to the scroller's padding edge, so a 12 px band of rows stays visible above it. `ListCard overflow-hidden` on other lists makes the header never stick at all | Card becomes the scroll container (no padding), header sticks at its top; one `DataGrid` used by every list | `queues/page.tsx`, `data-list.tsx` |
| 2 | Content slides **under** the top bar and stays faintly visible (Compliance 18:36:23) | OBSERVED: the window scrolls; the header is `sticky` with `bg-surface-raised/90 backdrop-blur`, so text shows through it; section tabs and toolbars scroll away while the table continues | App frame of fixed height: header outside the scroll area, `main` is the only page scroller, header opaque; anchor offsets need no magic numbers | `shell.tsx`, `globals.css` |
| 3 | "Off duty" checkbox **jumps** when clicked (home) | OBSERVED: right-aligned flex row; the label text swaps "Off duty"↔"On duty", so its width changes and the box moves | Switch with a fixed label ("On duty") and the state carried by the control | `admin/(app)/page.tsx`, new `Switch` |
| 4 | "Urgent only" checkbox moves when ticked (Requests) | OBSERVED: ticking makes `activeFilters > 0`, which **inserts** a "Clear" button into the wrapping toolbar and reflows every control after it | Clear button always rendered (disabled when nothing to clear); result count in a fixed slot | `queues/page.tsx` |
| 5 | Text too small everywhere | OBSERVED: `html { font-size: 13px }` shrinks every rem-based utility (spacing, `text-sm`, control heights) by 19%; on top, 9.5–11.5 px literals: of 660 text nodes on Requests, 545 are ≤ 13 px and 196 are 11–11.5 px | 16 px root; type scale tokens (12 / 13 / 14 / 15 / 18 / 22 / 28); 12 px floor for meta text | `globals.css`, components |
